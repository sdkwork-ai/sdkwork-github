# Roadmap

This directory holds product roadmap shards for the SDKWork GitHub application.

## Current Roadmap

### Phase 1: Core Tracker (Complete)

- Issue tracking with types (bug, feature, enhancement, question, task)
- Issue labels and filtering (type, status, priority, milestone, search)
- Issue voting and comments
- Milestones with progress tracking (open/closed issue counts)
- Roadmaps with timeline items and issue linking
- Full API surface under `/tracker/` namespace
- Frontend pages: Issues, Issue Detail, Roadmaps, Milestones

### Phase 2: Enhanced Workflows (Planned)

- Roadmap drag-and-drop reordering
- Milestone burndown charts
- Issue assignment workflows and notifications
- Custom fields beyond the unified issue model
- Board (Kanban) view for issues
